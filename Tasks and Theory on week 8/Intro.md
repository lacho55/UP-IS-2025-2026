# Въведение в динамична памет - Подгряващи задачи

## Задача 0.1 - Първа стъпка с динамична памет
Напишете програма, която:
1. Заделя динамично памет за едно цяло число
2. Присвоява му стойност 42
3. Извежда стойността на конзолата
4. Освобождава паметта

**Пример:**
```cpp
int* ptr = new int;
*ptr = 42;
cout << *ptr << endl;
delete ptr;
```

## Задача 0.2 - Динамичен масив с фиксирана дължина
Напишете програма, която:
1. Създава динамичен масив с точно 5 елемента
2. Попълва го с числата от 1 до 5
3. Извежда всички елементи на конзолата
4. Освобождава паметта

**Очакван изход:**
```
1 2 3 4 5
```

---

## Задача 0.3 - Динамичен масив с потребителски размер
Напишете програма, която:
1. Чете от потребителя цяло число n
2. Създава динамичен масив с n елемента
3. Попълва масива с числата от 0 до n-1
4. Извежда масива
5. Освобождава паметта

**Пример:**
```
Въведете n: 4
0 1 2 3
```

---

## Задача 0.4 - Сумиране на елементи
Напишете програма, която:
1. Чете от потребителя цяло число n
2. Създава динамичен масив с n елемента
3. Чете n числа от потребителя и ги запазва в масива
4. Изчислява и извежда сумата на всички елементи
5. Освобождава паметта

**Пример:**
```
Въведете n: 3
Въведете елемент 0: 10
Въведете елемент 1: 20
Въведете елемент 2: 30
Сумата е: 60
```

## Задача 0.5 - Намиране на максимум
Напишете програма, която:
1. Чете от потребителя цяло число n
2. Създава динамичен масив с n елемента
3. Чете n числа от потребителя
4. Намира и извежда най-голямото число в масива
5. Освобождава паметта

**Пример:**
```
Въведете n: 4
Въведете елемент 0: 5
Въведете елемент 1: 12
Въведете елемент 2: 3
Въведете елемент 3: 8
Максималният елемент е: 12
```

---

## Съвети за студентите:
- Винаги използвайте `new` за заделяне на динамична памет
- За масиви използвайте `new[]` (с квадратни скоби)
- Винаги освобождавайте паметта с `delete` или `delete[]`
- Не забравяйте: `new` → `delete`, `new[]` → `delete[]`
- При `new[]` използвайте `delete[]`, не просто `delete`!

---

## Важно напомняне:
**Memory leak** (изтичане на памет) се случва, когато заделите памет с `new`, но не я освободите с `delete`. Винаги освобождавайте паметта, която сте заделили!
